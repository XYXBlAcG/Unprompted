# Unprompted — 口语练习(中文复刻版)

完整复刻自 [https://www.unprompted.cool/](https://www.unprompted.cool/) 的单页口语练习应用,所有界面文案均已中文化,并在此基础上增加了词汇管理等功能。

## 功能

- **两种练习模式**
  - 🧠 即兴演讲:抽取话题后直接开始演讲计时,几乎不需要准备
  - 🔍 深度研究:先设置研究计时器,研究完成后手动进入演讲计时
- **话题领域选择**(即兴演讲模式):17 个领域(综合 / 个人理财 / 创业 / 初创公司 / 科技·AI / 健身 / 营养 / 效率 / 历史 / 文学 / 心理学 / 经济学 / 营销 / 管理 / 哲学 / 科学 / 设计),共 500+ 中文专业术语话题
- **话题转盘**:点击「抽取」随机滚动,约 5 秒后落定一个话题,带音效
- **计时器**
  - 演讲计时:1–10 分钟,倒计时圆环 + 三步演讲结构(是什么? / 所以呢? / 然后呢?)
  - 研究计时:1–60 分钟(仅深度研究模式),完成后进入「准备演讲」阶段
- **词汇管理(设置中)**
  - 按领域编辑词汇:单个添加、逐条删除
  - 批量导入:每行一个词汇,自动去除编号/圆点,适合把 LLM 生成的词汇直接粘贴导入
  - **LLM 生成提示词**:内置可复制的原始 prompt,自动包含当前领域、生成数量(可调)与「已有词汇清单」,让 LLM 生成数据库里没有的新词
  - **恢复默认**:带确认弹窗,防止误操作
  - **本地持久化与备份**:自定义词库保存在浏览器本地(`localStorage`,`unprompted:topics:<领域ID>`);支持一键导出为 JSON 文件备份/迁移,也可从 JSON 文件导入还原
- **设置**:演讲/研究时长滑块、静音开关,通过 `localStorage` 持久化(键前缀 `unprompted:`)
- **音效**:转盘滴答、落地和弦、结束提示音(Web Audio 合成,可静音)
- **无障碍**:键盘操作(方向键切换模式/领域、Tab 焦点陷阱、Esc 关闭)、ARIA 标注、`prefers-reduced-motion` 支持

## 技术说明

纯静态站点(原生 HTML/CSS/JS,无构建步骤、无依赖),与原文相同的暗色视觉设计:

- `index.html` — 页面骨架与中文元信息(`lang="zh-CN"`、SEO/OG 标签、PWA manifest)
- `styles.css` — 复刻原站设计系统(配色/排版/动画),字体栈适配中文字体
- `app.js` — 全部交互逻辑(原生 JS 复刻原 React 应用,含词汇管理)
- `favicon.svg` / `apple-touch-icon.png` / `og.png` — 原站图标与分享图
- `manifest.webmanifest` — PWA 清单(中文名称与描述)

## 本地运行

任意静态服务器即可,例如:

```bash
python3 -m http.server 5176
# 打开 http://127.0.0.1:5176/
```

> 注意:需通过 HTTP 访问(而非直接双击打开 `index.html`),`type="module"` 脚本与 manifest 才能正常加载。
